# DMart Ready – E-commerce Website

A front-end e-commerce website inspired by a DMart Ready shopping experience.

## Features

- Responsive header and navigation
- Location selection modal
- Login modal
- Automatic image slider
- Popular category slider
- Product cards rendered with JavaScript
- Add-to-cart and quantity controls
- Popular searches and category sections
- Footer with app/payment links
- Font Awesome icons

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Project Structure

dmart/

## Run Locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

After uploading the project to a public GitHub repository, enable GitHub Pages from:

**Settings → Pages → Deploy from branch → main → / (root)**
